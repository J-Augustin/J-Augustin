##  Featured Projects

###  [aws-enterprise](https://github.com/J-Augustin/aws-enterprise)
**Hybrid multi-account AWS landing zone — built with Terraform**

A production-grade AWS Organizations bootstrap with automated account provisioning, Service Control Policies, org-wide CloudTrail, centralized GuardDuty and Security Hub, and Direct Connect integration. Security and governance are the foundation, not an afterthought.

`Terraform` `AWS Organizations` `SCPs` `CloudTrail` `GuardDuty` `Security Hub` `IaC`

---

###  [FunFactory-Hybrid-AD-Lab](https://github.com/J-Augustin/FunFactory-Hybrid-AD-Lab)
**Enterprise Active Directory lab — fully scripted, migration-ready**

A fully scripted on-premises Active Directory environment simulating a real corporate datacenter: 1,000+ users across 10 departments, tiered admin model, 7 GPOs, a file server with ~500GB of migration test data, and a 4-phase roadmap to hybrid AWS integration via Client VPN, AWS Managed AD, and DataSync.

`PowerShell` `Active Directory` `VirtualBox` `AWS DataSync` `FSx` `Hybrid Identity`

---

###  [project-dns](https://github.com/J-Augustin/project-dns)
**Highly available hybrid DNS — AWS Route 53 & Terraform**

A multi-AZ hybrid DNS architecture using Route 53 Resolver, private hosted zones, and inbound/outbound endpoints — enabling seamless name resolution between on-premises Active Directory and AWS. Built entirely in Terraform with CloudWatch query logging and no single points of failure.

`Terraform` `Route 53` `Route 53 Resolver` `Hybrid DNS` `CloudWatch` `IaC`
